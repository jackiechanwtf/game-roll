# Источник каталога игр

В `catalogue.json` включены 500 ПК-игр из открытого набора **HowLongToBeat Games Scraper (2/16/2025)**, автор Zaire Ali.

- Датасет: https://www.kaggle.com/datasets/zaireali/howlongtobeat-games-scraper-2162025
- Исходные сведения о прохождении: https://howlongtobeat.com/
- Дата снимка: 16 февраля 2025 года. Каталог не обновляется автоматически.
- Лицензия исходного набора и подготовленного каталога: **CC BY-SA 4.0**, https://creativecommons.org/licenses/by-sa/4.0/

Из исходного CSV выбраны записи типа `game`, доступные на `PC`, с положительным `game_comp_main` и не менее 100 ответов в `game_comp_main_count`. Повторы по `game_game_id` убраны. Из подходящих игр взяты 500 с наибольшим числом ответов; итог отсортирован по названию.

Длительность получена из `game_comp_main`: секунды переведены в часы с округлением до одного знака. Это оценка прохождения **основного сюжета**, а не прохождения на 100%. Она относится к игре в целом, а не исключительно к ПК. Фактическое время у конкретного игрока может отличаться.

Сохранены только идентификатор, название, длительность, жанры, число ответов и ссылка на страницу игры. Изображения и описания не копируются. Подготовленный каталог распространяется на тех же условиях CC BY-SA 4.0 с указанием источника и изменений.

## Повторная подготовка

Для обычного запуска это не нужно: готовый каталог уже лежит в репозитории.

При необходимости скачайте ZIP со страницы датасета и выполните:

```bash
python scripts/prepare_catalogue.py /путь/к/архиву.zip
```

Скрипт использует только стандартную библиотеку Python.
